# DevVault 🚀

> Your personal developer knowledge library, code snippet manager, and resource tracker.

![DevVault Demo](https://via.placeholder.com/800x450.png?text=DevVault+App+Screenshot) <!-- Replace with a real screenshot or GIF later! -->

---

## ✨ Features

- **Code Snippet Management:** Save, organize, and retrieve reusable code snippets instantly.
- **Syntax Highlighting:** Powered by Prism.js to give your code blocks clean, professional formatting across multiple languages (JavaScript, SQL, Python, CSS, etc.).
- **Dark/Light Mode:** Fully responsive theme switcher that respects developer preferences and saves state locally.
- **Tag-Based Filtering & Search:** Quickly find what you need by searching titles or filtering by language tags.

---

## 🛠️ Tech Stack

- **Frontend:** React, Vite, TypeScript, Tailwind CSS, Lucide Icons, Prism.js
- **Backend:** Node.js, Express.js
- **Database:** MySQL Workbench / relational database storage
- **Deployment:** Vercel (Frontend)
